# MuYun 慕云

> A snug Obsidian theme for **long-form reading, fast writing & quick navigation**.
> 舒适阅读 · 高效写作 · 快速定位

## Highlights

- **Eye-friendly color system** — dark "ink paper" & warm-paper light scheme, body text tuned to a ~10:1 comfort contrast band; every accent color desaturated 30–40% with hue preserved
- **Three-tier heading colors** — H1 amber / H2 mallow purple / H3 link blue, with an H2 wayfinder stripe for high-speed scrolling
- **Navigation UI** — bold folder skeleton + active-file marker + parent-chain highlight in the file tree, outline panel with heading-colored level dots, tab indicator, quick-switcher selection bar, search hit highlighting
- **Restrained motion** — hover fades, expand slide-ins, checkbox pop-in; all ≤200ms, opacity/transform only, one-switch "Efficiency mode" kills every animation
- **Print/PDF ready** — exporting to PDF always yields a light paper document, even in dark mode
- **Zero external resources** — system font stack only, no remote imports (community guideline compliant)

## Install

- Community themes: search "MuYun" once listed
- Manual: put `manifest.json` and `theme.css` into `<vault>/.obsidian/themes/MuYun/`, then enable MuYun in Settings → Appearance

## Companion plugin (optional)

[MuYun Companion](https://github.com/GarrettFynn/obsidian-muyun/tree/plugin) adds JS-powered reading aids on top of the theme: reading progress bar, spotlight, edge minimap, resume reading, heading breadcrumb, reading stats, paragraph focus & typewriter scrolling — each with its own toggle.

## Style Settings

With the [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) plugin you can tune: link / bold / heading colors, inline title size, paragraph spacing, line-width presets (40/46/52rem), body contrast presets (soft/standard/firm), H2 stripe toggle, legacy dark accent, efficiency mode, motion speed and per-effect switches.

> Note: the dark interactive accent follows your Obsidian global accent color by design.

## 中文说明

MuYun（慕云）围绕三支柱设计：

- **阅读舒适** —— 墨蓝纸 / 晨光暖纸双底，正文对比压在 ≈10:1 舒适带，强调色降饱和保色相
- **写作高效** —— 编辑态与阅读态共用变量组，模式切换零跳变；配套插件提供段落聚焦、打字机滚动
- **快速定位** —— 标题三级色阶 + H2 路标条，文件树骨架与当前项锚、大纲层级点色、搜索命中高亮

安装：社区主题搜索 MuYun，或手动将 `manifest.json` 与 `theme.css` 放入 `<vault>/.obsidian/themes/MuYun/`。安装 Style Settings 后可调对比度三档、行宽三档、标题色等 18 项参数；深色交互色默认跟随 Obsidian 全局主题色。
